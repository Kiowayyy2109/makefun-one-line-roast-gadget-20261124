## The line

> My smartwatch congratulated me for standing up while I was sitting on the toilet, and honestly it's the only positive feedback I've had all week.

145 characters. The roast targets a gadget used every day, and the sting is
a real behaviour: the stand-up congratulation that fires at the least
dignified moment possible.

## Run it

```sh
python3 main.py
```

Writes the line, byte-exact with no trailing newline, to `/output/entry.txt`.
The program validates the line against the gate first (single line, 1–200
characters, not blank) and reads the file back to confirm the bytes match.
